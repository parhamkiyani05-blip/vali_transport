# VALI Transport System

نسخه پایه سیستم مدیریت آنلاین/آفلاین شرکت حمل‌ونقل VALI.

## امکانات فعلی
- ورود کاربران با نقش مدیر، دفتر‌دار و کارمند
- ورود آفلاین روی دستگاهی که قبلاً آنلاین احراز شده
- نمایش وضعیت آنلاین/آفلاین و تلاش برای همگام‌سازی هر ۳ ثانیه
- ثبت هزینه آفلاین و ارسال خودکار بعد از اتصال
- راننده‌ها: نام، شماره کامیون، شماره تماس، زبان فارسی/ترکی
- حساب شرکت‌ها فقط برای مدیر
- مبالغ دلار و تومان کاملاً مستقل
- تأیید/رد هزینه توسط مدیر یا دفتر‌دار
- حذف/ویرایش نهایی فقط مدیر و حذف نرم (بایگانی)
- کاربران و فعال/غیرفعال کردن توسط مدیر
- قالب فاکتور A5 با نسخه فارسی و Türkçe و ریزتراکنش

## ساختار
- `frontend/`: React + Vite + PWA
- `backend/`: Node.js + Express API
- PostgreSQL: دیتابیس اصلی

## اجرای محلی
1. PostgreSQL را بالا بیاورید:
   ```bash
   docker compose up -d
   ```
2. فایل محیط backend:
   ```bash
   cp backend/.env.example backend/.env
   ```
3. نصب:
   ```bash
   npm install
   ```
4. ساخت دیتابیس:
   ```bash
   npm --workspace backend run db:migrate
   npm --workspace backend run seed
   ```
5. اجرای API:
   ```bash
   npm run dev:backend
   ```
6. در ترمینال دوم:
   ```bash
   cp frontend/.env.example frontend/.env
   npm run dev:frontend
   ```

ورود اولیه پیش‌فرض seed:
- username: `admin`
- password: `Vali@12345`

**قبل از استفاده واقعی رمز را عوض کنید.**

## استقرار
برای تولید، frontend و backend را در دو سرویس جدا مستقر کنید و PostgreSQL مدیریت‌شده بدهید. مقدار `VITE_API_URL` باید آدرس API آنلاین باشد و `FRONTEND_ORIGIN` در API روی دامنه frontend تنظیم شود.

## مرحله بعدی توسعه
- صفحه حساب و ریزتراکنش واقعی راننده و شرکت
- گزارش روزانه/ماهانه
- فاکتور واقعی از تراکنش انتخاب‌شده
- بایگانی و لاگ فعالیت‌ها
- ویرایش کامل کاربران/راننده‌ها/شرکت‌ها در UI
- اعلان درخواست‌های تأیید
